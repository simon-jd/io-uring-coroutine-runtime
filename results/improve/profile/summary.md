# User-space instructions per request (callgrind), improvement round

Generated by `scripts/callgrind-profile.sh <build> <io> <cores> 16 8 <dir>` (one directory per
run: the callgrind dump, kvload's result, the server command) and
`scripts/callgrind-summary.py` (these tables). Closed-loop GET, depth 16, 64-byte values,
50 connections per server core, 8 s under callgrind on CPUs 10-15; builds with `-O3 -g`
from `.cache/imp/<name>`. `main` is a48c76c; c1 = in-slot call nodes; c2 = c1 + chunked
slot table (kept); c3 = c2 + one hash per key (kept); c4 = c3 + inline receive path
(rejected). Counts are work, not time: valgrind serializes the threads and does not see
the kernel.
