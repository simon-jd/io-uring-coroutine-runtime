# User-space instructions per request (callgrind)

Generated by `scripts/callgrind-profile.sh` (one directory per run: the
callgrind dump, kvload's result, the server command) and
`scripts/callgrind-summary.py` (these tables). Closed-loop GET, 64-byte
values, 50 connections per server core, 8 s under callgrind on CPUs 10-15.
Valgrind runs the server's threads one at a time: the counts are work, not
time, and the kernel's instructions are not seen. `main` is 3eb4121;
3796efd is main plus the engine change; 5d86cbd adds `call_all`; the
`cand-*` builds are the rejected window-1 candidates (main plus one change).
